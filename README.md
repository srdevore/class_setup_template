# edep_625_SEM

Teaching lectures, labs, and plans for EDEP 625 Structural Equation Modeling with student-facing website to share lectures &amp; other docs. 

Features: 

1. Class website with Syllabus info, lecture slides, and r labs that are automatically populated from slide/lab files. 
2. Profiles: teacher and student profiles allow for student version to be rendered on the site (i.e. without notes and answers to questions) and teacher version teacher version (with notes and answers) in html for instruction.
- students can download the student version as pdf.  
3. Class schedule: Weeks and dates automatically populated based on semester start/end date and class cadence.
